# Day 14 – Feature Engineering for Machine Learning

Today I learned how to prepare raw data so machine learning models can understand it.  
Feature engineering is the most important skill in ML because models can only learn from well-structured, clean features.

---

## What I learned
- What features are and why they matter  
- How to convert messy text data into numeric values  
- How to encode categorical columns  
- How to handle missing values  
- How to create new meaningful features  
- How to save a clean machine-learning-ready dataset  

---

## What I practiced
- Cleaning "baby_sleep" and "mom_sleep" columns  
- Creating numerical features using regex  
- Encoding mood categories  
- Filling missing values  
- Creating `sleep_difference` & `sleep_ratio`  
- Saving a processed dataset

---

## Takeaway
Feature engineering is the foundation of every ML project.  
The better your features, the smarter your model, even simple models perform extremely well when the data is clean and meaningful.
